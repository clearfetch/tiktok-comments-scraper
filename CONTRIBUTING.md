# About this repository

This repository is the documentation and examples for the
[tiktok-comments-scraper](https://apify.com/clearfetch/tiktok-comments-scraper) Actor. The Actor's source is not
published here.

`sample-output.json` has the shape and values of a real row from a real run, with the commenter's name, ids and
avatar replaced by placeholders, since commenters are private people.

Found a bug, or need a field that is not in the output? Open an issue here, or use the Issues tab on the Actor
itself. Both reach me.
